# Laptop Performance
Category: Hardware

## Overview
A slow or freezing laptop is usually caused by too many running applications, low disk space, pending updates or too many startup programs.

## Speed up a slow laptop
1. Save your work and restart the laptop; restart at least once a week.
2. Open Task Manager and close applications using high CPU or memory.
3. Free disk space so at least 15 percent of the drive is free.
4. Install pending Windows and security updates.
5. Disable unneeded startup applications in Task Manager.
6. Run the approved antivirus scan.
If an application is frozen or not responding, the helpdesk automation can restart it. For loud fan noise, overheating or poor battery life, raise an incident for Desktop Support.
