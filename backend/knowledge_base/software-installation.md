# Software Installation
Category: Software

## Overview
Only approved software from the software catalogue may be installed on company laptops. Employees do not receive local administrator rights; installation is pushed to the laptop automatically.

## How to request software
1. Submit a request in the self-service portal naming the software, for example Visual Studio Code.
2. Free developer and collaboration tools in the catalogue are pre-approved and are provisioned automatically within about 15 minutes.
3. Licensed software such as Microsoft Visio or Adobe Acrobat Pro needs manager approval before provisioning.
4. A service request number is created so you can follow the status until the installation completes.
Software that is not in the catalogue must be reviewed by IT Security before it can be installed.
