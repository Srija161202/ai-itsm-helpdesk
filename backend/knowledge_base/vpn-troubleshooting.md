# VPN Troubleshooting
Category: Network

## Overview
The corporate VPN client gives remote employees secure access to internal systems. Most VPN problems are caused by expired credentials, an outdated client, an unstable internet connection or an MFA prompt that was not approved.

## VPN authentication failures
If VPN authentication keeps failing, work through these steps:
1. Confirm you can sign in to the company portal with the same username and password.
2. If your password has expired, reset it using the Password Reset process and then reconnect the VPN.
3. Approve the MFA push notification within 30 seconds and make sure your phone time is set to automatic.
4. Check that your account is not locked after repeated failed attempts.
5. If it still fails, raise an incident for Network Support and include the exact error message.

## VPN connection problems
If the VPN will not connect or keeps dropping:
1. Check that your home internet works and try another network such as a mobile hotspot.
2. Quit and restart the VPN client, then select the nearest gateway.
3. Update the VPN client to the latest approved version from the software catalogue.
4. Disable other VPN or proxy software that may conflict with the corporate client.
