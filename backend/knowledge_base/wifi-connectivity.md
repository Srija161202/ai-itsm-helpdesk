# Wi-Fi Connectivity
Category: Network

## Overview
Employees should use the Corp-Secure wireless network on company laptops. The Guest network gives internet only and cannot reach internal systems.

## Wi-Fi will not connect or is unstable
1. Turn Wi-Fi off and on, or toggle airplane mode.
2. Forget the Corp-Secure network and reconnect with your corporate credentials.
3. Restart the laptop and move closer to an access point.
4. Run ipconfig /release and ipconfig /renew in a command prompt to refresh the IP address.
5. Update the wireless adapter driver through Windows Update.
If the problem continues across several locations, raise an incident for Network Support with the location and time.
